One line, a hundred and six characters, spoken by a smart speaker that has just switched itself off by mistake: the program drops it into `/output/entry.txt`.
The winning line reads "Sorry, I heard 'turn it down' and turned myself off. This apology is pre-recorded. Please don't unplug me."
Twelve lines were drafted by hand and graded on humour, freshness, machine voice and tightness; the field was already crowded with "I heard X as Y" jokes, so the winner earns its laugh a different way — a twist in every clause, ending on a recording that outlives the device. It got one more pass to strip every slack word before the punchline.
## How to run it
Run it with `python3 main.py` from this directory.
